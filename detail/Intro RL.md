# 强化学习
强化学习（英语：Reinforcement learning，简称RL）是机器学习中的一个领域，强调如何基于环境而行动，以取得最大化的预期利益。

## 基本过程
![loop](image.png)
上图描述了强化学习的基本框架
在每一个时间 $t$
- 观察状态：智能体（Agent）感知当前环境状态 $s_t$。
- 选择动作：智能体根据策略 $\pi(a_t | s_t)$ 选择动作 $a_t$。
- 环境反馈：环境执行动作后，返回新的状态 $s_{t+1}$ 和即时回报 $r_{t+1}$。
- 更新策略：智能体根据获取的状态和回报信息调整策略，以优化长期累积收益。

此过程循环进行，智能体通过试错不断改进策略，目的是得到最大化的回报。



## 蒙特卡洛学习
蒙特卡洛学习(Monte-Carlo Learning)是强化学习中常用的算法。

核心思想

- 智能体从当前策略出发，完整地进行一次试验（即从初始状态到终止状态的一整局），记录每一步的状态、动作和回报。

- 通过对多次完整试验的回报进行平均，估计每个状态（或状态-动作对）的期望回报。

- 利用这个估计值更新策略，使策略向更优方向调整。



## 案例
例如，在井字棋游戏中
| 强化学习元素            | 对应                                                                
|                   --------------- | ----------------------------------------------------------- |
| **Agent（智能体）**     | 下棋的一方（可以是 AI 或训练的程序）                        |
| **Environment（环境）** | 棋盘状态 + 对手动作的系统                                   |
| **State（状态）**       | 当前棋盘格局，例如 `[['-1','1',''],['','-1',''],['1','','']]` |
| **Action（动作）**      | 在空格中落子，例如 `(0,2)` 表示在第一行第三列下子   |
| **Reward（回报）**      | 对局结果给出的反馈：<br>赢 +1，输 -1，平局 0                |
| **Policy（策略）**      | 智能体选择落子位置的规则，可以是随机、贪心或经过训练的策略  |
